# Starter REPAR.ar

1. `npx create-next-app@latest repar-ar` (TypeScript, Tailwind, App Router, alias `@/*`).
2. Copiá dentro del proyecto: `app/`, `lib/`, `public/`, `referencia/` y `PROMPT.md`.
   `app/layout.tsx` y `app/globals.css` pisan los que genera create-next-app.
3. Abrí Claude Code en esa carpeta y pegale el contenido de `PROMPT.md`.
